# Upload the 1918 "Tag Every Voter" Notice to Wikimedia Commons

Backlogged November 1, 2026 (Garrett: "it should be on the Wikipedia I Voted sticker page, I think. Let's
backlog it"). Not started. Garrett uploads; Claude never posts to Wikipedia or Commons.

## Why

The Commons category "I voted" stickers of the United States has nothing earlier than the 1920
Nineteenth Amendment badge. The October 31, 1918 Lowell Ledger notice is the earliest record we found of
"I am an American. I voted. Did you?" tags, and it is public domain (published in the US before 1929).
A Commons file is something Wikipedia editors can use, including whoever answers the Talk page edit
request (`docs/wikipedia-talk-request.html`). Uploading a public-domain historical scan with its archive
source is an ordinary contribution, not a conflict-of-interest edit.

## The File

`lowell-ledger-1918-10-31-tag-every-voter.png` in this folder: 680 x 690 px, rendered at 300 dpi from the
Kent District Library PDF (page 2, editorial column). Contains only the notice paragraph.

Do not upload: the 1950 "Thank Me I Voted Republican" sticker (gallery rights statement is
education-only, not a free license), the 1952 Lowell Ledger (renewal status unchecked), or any
VoteSticker.org design (out of scope, promotional).

## Steps

1. Wait for the Talk page edit request to be posted (and ideally answered), so the upload and the
   request support each other.
2. Logged in as Usableweb, open https://commons.wikimedia.org/wiki/Special:UploadWizard and upload the
   PNG. Choose "This file is not my own work" and the public-domain option for works published before
   1929, then paste the description below in place of the wizard's fields if it offers source mode.
3. Add it to the category. Optionally reply on the Talk page that the image is available.
4. Garrett may later suggest it in the article itself through another `{{edit COI}}` request; don't add
   it to the article directly.

## Source Check (done November 1, 2026)

Read on the scan: "Recently the Americanization society inaugurated a movement to tag every voter,
which has already brought good results. The effort will be continued in the November election and tags
bearing the words "I am an American. I voted. Did you?" Will be distributed." Gavit's *Americans by
Choice* (1922), pp. 330–333, ties the same tag to the Grand Rapids Americanization Society.
