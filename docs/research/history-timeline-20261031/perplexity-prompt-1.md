# Perplexity prompt 1 (Deep Research, VoteSticker.org Research project, Oct 31 2026)

I run https://votesticker.org/history/ (Spanish at /es/history/), a free nonpartisan page on the history of the "I Voted" sticker. It's plain server-rendered PHP, HTML, SVG and CSS (no chart library, no framework). Every claim has a primary or contemporary source.

The page has an overview timeline chart near the top. Its job: an at-a-glance overview of about 26 dated events from 1888 to 2026, where each mark links (#anchor) to a longer entry in a vertical list below it. Events (year, short label if it gets a visible label, kind):
1888 Secret ballot (before stickers); 1920 St. Louis school "I have voted" tags (before stickers); 1920 Ribbon (before stickers); 1950 Miami newspaper mention (evidence incomplete); 1962 Camp Fire Girls tags; 1966 Georgia polling place tags; 1982 Fort Lauderdale discounts for sticker wearers (sticker); 1984; 1985 Phoenix campaign (sticker milestone); 1986 stickers for sale; 1987 Flag oval (milestone); 2006 neighbors-see-you mailer study (research); 2008 freebies vs election law; 2008 Facebook "I Voted" button (digital); 2010 Facebook; 2014 stickers on Susan B. Anthony's grave; 2016 Chicago wristbands; 2017 NYC subway sticker; 2018 Instagram sticker (digital); 2019 EAC award; 2019 mailed sticker; 2020 Alaska ten languages (digital); 2020 Nashville runs out; 2022 Ulster County (milestone); 2024 Michigan statewide contest; 2026 Michigan 2,095 entries.
Marker shapes encode kind (open circle = before stickers, filled oval = sticker milestone, diamond = digital, dashed circle = evidence incomplete); a key names them in words.

Current problems: a linear year scale 1880 to 2030 in a 960x172 SVG viewBox, so 1888 to 1980 is mostly empty and 2008 to 2024 markers pile up; labels collide ("2008 Facebook" over "2016 Instagram", "1985 Phoenix" crowds "1987 Flag oval", two 2020-ish labels overprint); a min-width:640px track inside overflow-x:auto gives a horizontal scrollbar at mid widths and a tiny scroll strip on phones; the key sits loosely outside the panel. Spanish labels run longer.

A sister site uses a pattern I like: an HTML (not SVG) milestone list that is a horizontal row of equal flex columns on desktop (dot on a connecting line, year, short label), auto-switches to a vertical stack under 640px or when there are more than 7 items or long details, has an era "separator" that adds a gap before a new era, and an sr-only text fallback. It also has an event-density strip (counts per period) and a "then/now" comparison.

Please research and recommend, with examples from good editorial or museum sites (NYT, Washington Post, Pudding, Reuters Graphics, Smithsonian, OWID, BBC, Datawrapper/Flourish docs) and accessibility guidance:
1. How to build a responsive history timeline overview that works from 320px to 1440px with no horizontal scrolling: compressed or broken axis vs era segments sized by event density (with a visible break marker), label stacking and collision avoidance (2-3 rows, leader lines, grouping same-year or clustered events into one labeled cluster), vertical timeline on mobile, which events get visible labels. Plain HTML/SVG/CSS, no scrollytelling.
2. Accessibility: tap targets (44px), focus states, accessible names for linked marks, reduced motion, and whether the chart should be aria-hidden when the list below repeats it.
3. CSS layout ideas for the whole page as a strong editorial page: section rhythm, measure, the event list under the chart (year column, source badges), source lines, figures, a "What we still don't know" block, desktop and mobile.
4. How to make the page more human, helpful and evidence-backed, and 10x better than competing "history of the I voted sticker" pages (AARP, Time, Smithsonian, Vox, Wikipedia, Mental Floss and similar). What do they all miss? Ideas only.
Give concrete, specific recommendations, and cite the sources you used.
